# Лабораторная работа №9. Методы Java. Перегрузка методов

## Задание 1. Методы с возвращаемыми значениями

Оба метода объявлены внутри класса `MainActivity` с модификатором `private`: они нужны только этой активности.

**calculatePower(int base, int exponent)** возвращает `int`. Переменная `result` начинается с 1 (нейтральный элемент умножения), и цикл `for` выполняется `exponent` раз, каждый раз умножая результат на `base`. При `exponent = 0` цикл не выполняется ни разу и метод возвращает 1, что верно математически.

**getGreeting(String name)** возвращает `String`: склеивает «Привет, », имя и восклицательный знак оператором `+`.
