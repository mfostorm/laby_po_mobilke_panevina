# Лабораторная работа №10. Рекурсивные методы

Рекурсивный метод вызывает сам себя. Чтобы цепочка вызовов закончилась, в каждом методе есть **базовый случай** (условие выхода без нового вызова), а каждый рекурсивный вызов делает шаг, приближающий к нему.

## Метод countUp — числа от 1 до N

По заданию метод принимает только `n`, но для счёта вверх нужно помнить, на каком числе мы сейчас. Поэтому `countUp(int n)` вызывает перегруженную версию `countUp(int current, int n)`: она выводит `current` и вызывает себя с `current + 1`. Базовый случай: `current` дошёл до `N`.

## Метод countDown — числа от N до 1

Число выводится **до** рекурсивного вызова, поэтому печать идёт по убыванию. Каждый вызов уменьшает `n` на 1. Базовый случай: `n == 1` (условие `<=` защищает от зацикливания при `n <= 0`).

@code код/MainActivity.java#countDown

## Метод sumNumbers — сумма чисел от 1 до N

Используется формула sum(n) = n + sum(n − 1), базовый случай sum(1) = 1. Для `n = 5` вычисление разворачивается так: 5 + (4 + (3 + (2 + 1))) = 15. Результаты складываются при возврате из вызовов, от самого глубокого к первому.
