# Лабораторная работа №13. Инкапсуляция, конструкторы и статические методы

## Класс SpaceShip

@code код/SpaceShip.java

Что здесь важно:
- **Конструктор** `SpaceShip()` вызывается автоматически при `new`. Он увеличивает счётчик кораблей и задаёт начальную прочность 100.
- **`static int totalShips`** — одна переменная на весь класс, общая для всех объектов. Поэтому счётчик показывает количество всех кораблей, а не данные одного из них.
- **`static getTotalShips()`** вызывается через имя класса, без объекта: `SpaceShip.getTotalShips()`.
- **`this.hullStrength = hullStrength`**: имя параметра совпадает с именем поля, и `this` явно указывает на поле объекта.
- `setHullStrength` и `destroyShip` закрыты (`private`): прочность меняется только изнутри класса, через конструктор и `takeDamage()`.

> В `takeDamage()` добавлена проверка «корабль уже уничтожен». Без неё повторное попадание по разбитому кораблю снова вызвало бы `destroyShip()`, и `totalShips` уменьшился бы второй раз. Тогда в конце вывелся бы 0, а не ожидаемая 1.
