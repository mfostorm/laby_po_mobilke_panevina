# Задание №7. Java-методы

## Задача 1. Разбор объявлений методов

| Объявление | Модификатор доступа | Возвращаемый тип | Имя | Параметры |
|---|---|---|---|---|
| `protected double calculateTax(...)` | `protected` | `double` | `calculateTax` | `double income`, `boolean isResident` |
| `static boolean validateEmail(...)` | не указан (default, доступ в пределах пакета); `static` — не модификатор доступа | `boolean` | `validateEmail` | `String emailAddress` |
| `public void printReport()` | `public` | `void` | `printReport` | нет |
| `private static String[] sortArray(...)` | `private` (+ `static`) | `String[]` (массив строк) | `sortArray` | `String[] inputArray`, `int order` |

**Может ли void-метод содержать return?** Да, но только без значения: `return;`. Он нужен для досрочного выхода из метода, например при неверных входных данных или когда результат уже найден. `return значение;` в `void`-методе вызывает ошибку компиляции.

**Что возвращает метод с типом boolean?** Одно из двух логических значений, `true` или `false`. Обычно это результат проверки условия.

## Задача 2. Ошибки в классе MethodErrors

| Строка | Ошибка | Исправление |
|---|---|---|
| 11 | Нет `;` в конце оператора `int result = a + b` (синтаксическая) | `int result = a + b;` |
| 16 | `string` с маленькой буквы — такого типа нет, Java чувствительна к регистру | `String name` |
| 18 | `void`-метод возвращает значение `"Greeting printed"` | удалить `return` (метод только печатает) |
| 23 | `if (num > 0);` — точка с запятой завершает `if` пустым оператором, и `else` остаётся «без if» | `if (num > 0) {` |
| 34 | `firstInit + lastInit`: сложение двух `char` даёт `int` (сумма кодов символов), а не строку из двух букв. Это ошибка компиляции и логическая ошибка: инициалы — это два символа, а `char` вмещает один | возвращать `String` |

Исправленный класс:

```java
public class MethodErrors {

    public int addNumbers(int a, int b) {
        int result = a + b;
        return result;
    }

    private void printGreeting(String name) {
        System.out.println("Hello, " + name);
    }

    boolean checkPositive(double num) {
        if (num > 0) {
            return true;
        } else {
            return false;
        }
    }

    public String getInitials(String firstName, String lastName) {
        char firstInit = firstName.charAt(0);
        char lastInit = lastName.charAt(0);
        return "" + firstInit + lastInit;   // "" превращает выражение в строку
    }
}
```

```
MethodErrors.java:25: error: 'else' without 'if'
MethodErrors.java:34: error: incompatible types: possible lossy conversion from int to char
```

## Задача 3. Класс CalculatorUtils

@code код/CalculatorUtils.java ~ public class CalculatorUtils ~ // Задача 4

Методы объявлены `static`, потому что им не нужны поля объекта, и вызывать их удобно прямо через имя класса: `CalculatorUtils.multiply(6, 7)`.

**Почему у printSquare тип void, а не String?** Задача метода — вывести квадрат на экран, то есть совершить действие, а не вычислить значение. Возвращать нечего. Если бы метод возвращал `String`, ему пришлось бы собирать строку, а вызывающему коду — выводить её самому. Для простого вывода это лишняя работа. `void` прямо показывает, что метод «делает», а не «считает».

## Задача 4. Метод isDiscountAvailable

**A. Сигнатура:**

```java
public boolean isDiscountAvailable(boolean isRegularCustomer, double purchaseAmount)
```

**B. Полный метод:**

```java
public boolean isDiscountAvailable(boolean isRegularCustomer, double purchaseAmount) {
    if (isRegularCustomer || purchaseAmount > 1000.0) {
        return true;
    } else {
        return false;
    }
}
```

Блоки `private`, `void` и `(double purchaseAmount, boolean isRegularCustomer)` не понадобились: по условию параметры идут в другом порядке, а метод должен возвращать результат.

**Почему boolean лучше, чем void?** Метод отвечает на вопрос «да или нет», и вызывающий код должен получить ответ. С `void` результат проверки остался бы внутри метода. Его нельзя было бы использовать в условии (`if (isDiscountAvailable(...))`), сохранить в переменную или передать дальше. Метод мог бы разве что напечатать ответ.

## Задача 5. Трассировка программы TraceMe

```
Шаг 1
Привет из метода!
Шаг 2
Удваиваю число: 3
Удвоенное число: 6
Шаг 3
Сумма равна: 12
Конец программы
```

Методы выполняются по порядку вызова в `main`. `doubleNumber(3)` сначала печатает свою строку и только потом возвращает 6 в переменную `result`.

**Что будет без return в doubleNumber?** Метод объявлен с типом `int` и обязан вернуть значение на любом пути выполнения. Без `return` компилятор выдаст `error: missing return statement`. Это **ошибка компиляции**: программа даже не запустится.
