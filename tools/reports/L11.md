# Лабораторная работа №11. ООП. Классы

Класс — это шаблон, в котором описаны поля (данные) и методы (поведение). Объект создаётся оператором `new`, и у каждого объекта свой набор значений полей. Доступ к полям и методам идёт через имя объекта и точку: `enterprise.shield`, `enterprise.fireLasers()`.
