Большинство ссылок объявлены `final`, потому что они используются внутри анонимных классов-слушателей. `final` запрещает менять саму ссылку, но не объект: у `imageView` по-прежнему можно менять прозрачность, цвет и размер. При запуске `textView` скрыт.

## Чекбоксы

Для каждого `CheckBox` создаётся анонимный класс `CompoundButton.OnCheckedChangeListener`. Его метод `onCheckedChanged` срабатывает при каждом переключении галочки.

@code код/MainActivity.java ~ // Чекбоксы ~ imageView.setScaleY(1);


- **Transparency** — `setAlpha(.1f)` делает картинку почти прозрачной, `setAlpha(1f)` возвращает её.
- **Tint** — `setColorFilter(Color.argb(150, 255, 0, 0))` накладывает полупрозрачный красный слой. Аргументы задают альфу, красный, зелёный и синий; `argb(0, 0, 0, 0)` снимает оттенок.
- **Re-size** — `setScaleX(2)` и `setScaleY(2)` увеличивают картинку вдвое, а значение 1 возвращает исходный размер.

## Радиокнопки

`clearCheck()` снимает все отметки при старте. Слушатель `RadioGroup.OnCheckedChangeListener` получает `checkedId` — id выбранной кнопки. По нему находится сама `RadioButton`, и часам задаётся часовой пояс через `setTimeZone()`.

@code код/MainActivity.java ~ // Радиокнопки ~ America/New_York

Проверка на `null` нужна потому, что `clearCheck()` тоже вызывает слушатель, но с `checkedId = -1`, и кнопку по нему найти нельзя.

## Кнопка Capture и Switch

Для единственной кнопки удобно использовать анонимный `View.OnClickListener`: `getText()` берёт текст из `EditText`, а `setText()` записывает его в `TextView`. Switch по значению `isChecked` показывает или скрывает `TextView`.

## Результат работы
