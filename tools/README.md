# Сборка отчётов

- `reports/*.md` — исходные тексты отчётов. Код в них не копируется, а подставляется из папок `код/`:
  - `@code путь` — файл целиком;
  - `@code путь#метод1,метод2` — методы или конструкторы по имени;
  - `@code путь ~ начало ~ конец` — фрагмент между строками с таким текстом.
- `@out имя` подставляет реальный вывод программы из `out/имя.txt`.

```bash
# 1. Проверить код: компиляция против android.jar и запуск Log-приложений на JVM
#    (результат запуска сохраняется в tools/out/)
ANDROID_JAR=/путь/к/android-35/android.jar python3 tools/check_code.py

# 2. Собрать все отчёты .docx (нужен npm-пакет docx), или только некоторые: L13 Z07
node tools/build_reports.js
```
