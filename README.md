# Лабы по мобильной разработке (Java, Android)

```
отчёты/         — ВСЕ ГОТОВЫЕ ОТЧЁТЫ (.docx) в одной папке
задания/        — условия заданий (.docx) + код к каждому заданию
лабораторные/   — условия лабораторных (.docx) + код к каждой ЛР
tools/          — сборка отчётов и проверка кода
android/        — все приложения одним проектом Android Studio + задача автоскриншотов
screenshots/    — снимки экранов и Logcat с эмулятора (исходники для рисунков в отчётах)
```

Отчёты (без титульника: код с пояснениями, скриншоты, ответы на вопросы) лежат в `отчёты/`.
В папке каждой работы — `код/` с исходниками Java/XML для проекта Android Studio (Empty Views Activity).
