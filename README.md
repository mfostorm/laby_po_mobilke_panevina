# Лабы по мобильной разработке (Java, Android)

```
задания/        — теоретические задания: условия (.docx) + папка с отчётом на каждое задание
лабораторные/   — лабораторные работы: условия (.docx) + папка на каждую ЛР
tools/          — сборка отчётов и проверка кода
android/        — все приложения одним проектом Android Studio + задача автоскриншотов
```

В папке каждой работы лежат:
- **отчёт `.docx`** — без титульника: код с пояснениями, вывод Logcat, ответы на вопросы;
- **`код/`** — исходники Java/XML, которые можно вставить в проект Android Studio (Empty Views Activity).
