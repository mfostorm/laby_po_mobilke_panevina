# LabsRunner — все приложения в одном проекте + автоскриншоты

Проект сам находит все папки `код/` с `MainActivity.java` и делает из каждой отдельный модуль
(`:spacefleet`, `:javameetui`, …). Исходники копируются из `код/` при каждой синхронизации,
поэтому оригинал один — папка `код/`.

## Как снять скриншоты
1. Запустить эмулятор (Device Manager → ▶).
2. Android Studio → File → Open → выбрать эту папку `android` → дождаться синхронизации Gradle.
3. Справа панель **Gradle** (слон) → LabsRunner → Tasks → **labs** → двойной клик по **screenshots**.
4. Через 3–5 минут в корне репозитория появится папка `screenshots/`:
   - `<приложение>__logcat.txt` и `__screen.png` — для приложений, пишущих в Logcat;
   - `javameetui__*.png`, `widgetexploration__*.png`, `widgets__*.png` — экраны после нажатий
     (сценарии в `uitests/<имя>/ScreenshotTest.java`).

Запустить одно приложение вручную: выбрать модуль в выпадающем списке рядом с ▶ и нажать Run.
