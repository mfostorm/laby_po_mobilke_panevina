# Задания

Файлы `Задание №N.docx` — исходные условия. Код лежит в папках `Задание NN …`, готовые отчёты — в `отчёты/` в корне.

Нумерация уточнена:
- `Задание №11..docx` (с точкой) — «Наследование и полиморфизм»;
- `Задание №13.docx` на самом деле Задание 14 (массивы, HashMap, RecyclerView);
- настоящее Задание 13 — приложение с виджетами и слушателями (условие прислано в чате).
